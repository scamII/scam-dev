# Политика безопасности

## Поддерживаемые компоненты

| Компонент | Поддерживаемая линия |
|---|---|
| Тема Scam Dev | 1.3.x |
| Bundled plugins | 1.1.x |

Старые версии получают исправления только после отдельного решения владельца проекта.

## Сообщение об уязвимости

Не создавайте публичный issue и не публикуйте exploit до выпуска исправления.

Используйте private GitHub Security Advisory репозитория:

`scamII/scam-dev` → **Security** → **Advisories** → **New draft security advisory**.

В отчёте укажите:

- затронутый commit/version;
- компонент и файл;
- prerequisite роли/конфигурации;
- минимальный proof of concept;
- impact;
- предложения по исправлению;
- разрешение на указание автора отчёта.

## Обработка

1. Первичное подтверждение — по возможности в течение 72 часов.
2. Проверка воспроизводимости и severity.
3. Исправление в private branch/advisory.
4. Regression test.
5. Выпуск patched version.
6. Публикация advisory после доступности обновления.

## Секреты

Matrix/VK tokens, DB-пароли и Ed25519 private update key никогда не должны
храниться в Git. При подозрении на утечку ключ необходимо немедленно отозвать
и заменить.
